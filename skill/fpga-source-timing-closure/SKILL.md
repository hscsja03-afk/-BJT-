# FPGA 源码重建与时序核对

形式：工程工作流

## 适用场景

迁移旧工程、变更采样时钟、检查外部 IO 时序。

## 使用方法

收集 RTL/IP、约束和 PS 预设，以脚本重建工程。先验证复位和握手，再执行综合、实现与时序检查；同时记录内部路径、输入输出约束、跨时钟域及资源占用。优化前后使用相同负载和统计口径。

输出按[实验记录模板](../templates/experiment_record.md)填写输入、步骤、结果与复用条件。

## 协作提示词

> 请根据[源码、约束、综合和实现报告]定位限制频率的路径，保留失败约束，比较优化前后时序、资源与相同任务的耗时。

方括号由使用者替换为目标项目资料。

## 已验证效果

ADC62.5/DAC125 构建记录的建立/保持裕量为 0.394/0.041 ns；两档数字验证分别记录。

## 经验来源

旧工程缓存和时钟变更容易造成“构建成功”与实际约束不一致；采样率提高也改变模拟校准条件。

## 失效条件与处理

目标器件、IO 电压、板级延时和 IP 版本改变时重新建立约束。时序裕量对应指定构建，电压精度使用独立校准结果。
