# 可复用技能包

本目录整理 Zynq 多功能测量平台开发中的协作方法、校验工具和排错经验。按任务选择技能，替换板卡、接口、文件路径与验收条件即可复用。包含 9 项技能、两组独立校验脚本及实验/参数记录模板。

## 快速使用

1. 从下表选择任务，打开对应 `skill.md`。
2. 按入口准备输入并替换提示词中的方括号字段。
3. 运行操作步骤，填写 [实验记录](templates/experiment_record.md)，保存实际验证结果。
4. 换题目或板卡时重新填写接口与硬件条件。完整复制 `skill/` 可保留所有相对引用。

## 通用 PYNQ 校验

`pynq-overlay-audit` 通过清单输入位流、HWH、外设实例和地址，脚本不固定板卡、题目或工程路径。`--example` 输出清单格式；自带测试覆盖合法配置、地址错误和哈希错误。PS/DDR、电压与模拟条件按目标板另行核对。

## 单独复制后的使用

复制整个 `skill/` 目录即可带走说明、提示词、模板、脚本、测试和许可。在复制后的目录内执行：

```sh
python pynq-overlay-audit/scripts/check_bundle.py --example
python -m unittest discover -s pynq-overlay-audit/scripts -p "test_*.py" -v
python -m unittest discover -s register-to-analog-debug/scripts -p "test_*.py" -v
```

两组脚本仅使用 Python 标准库。处理自己的工程时，将位流、HWH、外设实例和地址填入清单，运行 `check_bundle.py path/to/manifest.json`；路径相对于清单所在目录解析。其余流程使用各项 `skill.md` 的输入条件和操作步骤，并填写本目录的实验模板。

通用 PYNQ 校验以文件和清单为输入，可以独立于本项目使用。测试包含 `image_filter_0` 与 `motor_ctrl_1` 两种外设实例、不同地址窗口以及从其他工作目录执行的情况；这些合成用例检查工具的通用性和路径处理。
