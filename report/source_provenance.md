# 文件来源与许可

本项目新增程序、脚本和说明采用根目录 license.txt 中的 MIT 许可。第三方代码、硬件资源、数据手册、字体及运行库保持各自版权与许可。

触摸模块 src/rtl/touch/ 保留正点原子原始文件头。RTL、约束和显示资源的原始成员及哈希保存在 source_records 数据归档中，使用 build/checks/restore_archives.py 还原后查看 report/original_source_manifest.json。

校准数据保留测量条件和数据身份。报告的来源及哈希见 [报告索引](indexes/document_sources.json)。[工程文件清单](../manifest.json) 记录仓库文件；[归档清单](../build/archive_manifest.json) 记录数据归档与运行库成员。

开发过程记录包含摘要及部分原文，保留原记录类型和时间。
